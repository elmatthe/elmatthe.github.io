“A compatible Python was not found” and winget isn't available (Windows)

Install Python 3.13 from python.org using the standard installer (Install for me only is fine), then run the launcher again. The launcher never uses the Microsoft Store python.exe placeholder.

Python is installed but “missing: tkinter” (macOS)

Homebrew's Python ships without the GUI toolkit. Let the launcher install python-tk@3.x when it asks, or run brew install python-tk@3.13 yourself. The python.org installer already includes it.

“Dependency installation failed”

The package download needs internet access to pypi.org. On a work network, a proxy or firewall may block it: try another network or ask IT. Also check free disk space. Running the launcher again resumes from where it stopped; nothing half-installed is used.

“The existing .venv is in use”

Another copy of the program (or a terminal using its Python) is still open. Close it and run the launcher again.

The window closes or an error mentions a missing file

Extract the whole ZIP again into a normal folder, not a cloud-sync placeholder or the ZIP preview, and keep the folder structure intact. The setup log in files/test-logs/ shows the last step that ran.
