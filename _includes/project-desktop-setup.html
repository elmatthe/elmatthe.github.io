Before you start

Operating system
Windows 10 or 11, or macOS 12 or later.
Python
You don't need to install it yourself. The launcher uses an existing Python {{ p.python }} (with tkinter) or offers to install one for your user account only.
Administrator rights
Not needed. Nothing is installed for all users.
Internet
Needed for the first setup (to download Python packages){% if include.live %} and for live Yahoo Finance data{% endif %}.
Disk space
About {{ include.disk | default: "400 MB" }} for the private Python environment inside the folder.

Only want to try it? The web version runs in your browser with nothing to install.

Install and first run

  1. Download {{ p.zip_name }} and extract it somewhere you can write to, such as Documents. Keep the {{ include.folder }} folder together; don't run the program from inside the ZIP.
  2. Double-click the launcher in that folder:
    • Windows: {{ p.launcher_windows }}. If SmartScreen warns about a downloaded file, choose More info → Run anyway only if you trust the source; on a work PC, ask IT first.
    • macOS: {{ p.launcher_macos }}. The first time, macOS may say it “cannot be opened”: open System Settings → Privacy & Security and click Open Anyway.
  3. Answer any simple prompt. If no suitable Python is found, you're asked before anything is installed (Y/N on Windows; a numbered menu on macOS).
  4. The program opens once the environment has been proven healthy. Keep the setup window open while you use it; closing the program returns you to it.
What the launcher does, step by step
  1. Assess: checks the private .venv in the folder: its Python version, exact package versions, and that every package actually imports.
  2. Reconcile: if something is wrong, it repairs only that part. A damaged or missing .venv is rebuilt from a separate Python; drifted or missing packages are reinstalled to the pinned versions.
  3. Provision (only if needed): with your permission, installs Python for your user. On Windows it uses winget (Python 3.13, user scope, PATH unchanged). On macOS it uses Homebrew (python@3.13 + python-tk@3.13), or you can use the python.org installer instead.
  4. Prove: re-checks everything after repair before launching.
  5. Launch and report: starts the program and reports how it finished.

Healthy later launches only run the quick check and start immediately, with no downloads. Setup scratch files and the package cache stay in files/temp/; the last setup log is files/test-logs/setup-and-run-latest.log.

Update, move or remove

  • Update: download the new ZIP and extract it to a new folder. The launcher builds a fresh environment on its first run. Copy over any exports you want to keep.
  • Move: after moving the folder, just run the launcher. It detects that the old .venv no longer works and rebuilds it.
  • Reset: delete the .venv folder and run the launcher again.
  • Remove: delete the folder. The only thing installed outside it is a per-user Python, if you agreed to install one, which you can keep or uninstall normally.
