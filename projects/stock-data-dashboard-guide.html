Using the tool

  1. Enter the securities: set how many, click Apply, and type each Yahoo Finance symbol (for example AAPL, XIU.TO, ^GSPC) with its listing currency.
  2. Choose the settings: Data source (Yahoo Finance or Offline CSV), Frequency (daily, weekly, monthly), Price type, Return type, Regression mode, start/end dates, risk-free rate and benchmark.
  3. Optional: Normalize to currency converts every price to USD, CAD, EUR or GBP before any maths, using Yahoo Finance FX pairs such as CADUSD=X. If a pair is unavailable, that security stays in its own currency and a warning says so.
  4. Click Fetch & Analyze. Results fill the tabs: metrics, correlation, diversification, regression, plots and warnings. Use Export Results to save them and Clear to start over.

Offline CSV mode

Works with no internet connection. Choose Offline CSV, point Offline folder at a folder of CSVs, and use dates that the files cover. The included sample is test-files/sample_prices.csv (dates 2024-01-02 to 2024-01-04) with test-files/fx_rates.csv for normalization. Expected format:

Date,Ticker,Close,Adj Close,Currency
2024-01-02,AAPL,185.64,184.91,USD

One file per ticker (named after the ticker) also works. FX files use Date,Pair,Rate where Pair is <FROM><TO>.

Outputs

  • Metrics: total and annualised return, annualised volatility, Sharpe ratio, max drawdown, observations, data completeness and currency.
  • Charts: indexed price, cumulative return, correlation heatmap, risk/return scatter, drawdown, rolling volatility, rolling correlation, regression scatter.
  • Export Results writes to your export folder: an Excel workbook (Dashboard Metrics, Correlation Matrix, Regression Results, Charts, Warnings), a CSV folder with the same tables, and JPG copies of the charts.

Troubleshooting

“No data” for a ticker

Check the symbol on finance.yahoo.com. Canadian listings need .TO/.V, indexes start with ^. Yahoo Finance sometimes rate-limits; wait a few minutes and try again.

Offline CSV says the data doesn't overlap the dates

The sample covers only 2024-01-02 to 2024-01-04. Set those dates, or switch to Yahoo Finance for recent data.

A currency-mismatch warning appears

Comparing securities listed in different currencies mixes FX moves into returns. Turn on Normalize to currency or make sure each row's currency is correct.

For developers

The program is in scripts/ (main.py GUI, data_sources.py for Yahoo Finance/offline CSV, analytics.py, plots.py, exports.py). Yahoo Finance is the only online data provider. The unit tests are in the source repository (files/tests) and aren't included in the ZIP:

.venv/bin/python -m pip install pytest
.venv/bin/python -m pytest files/tests -q

On Windows use .venv\Scripts\python.exe. The web version on the project page is a separate client-side implementation; see its comparison table.
