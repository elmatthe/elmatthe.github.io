Overview

  • One click, 18 series

    Five Statistics Canada CPI series and thirteen FRED series: US CPI, unemployment, fed funds, Treasury yields, the 10y–2y spread, PCE, and the S&P 500.

  • Straight into Excel

    Writes to the CPI_Downloader sheet of your .xlsx or .xlsm model through desktop Excel, and can also save the same data as CSV.

  • Validated first

    All sources are collected and checked before Excel opens. If any source fails, nothing is written.

Desktop only. The tool updates an existing model through desktop Microsoft Excel for Windows, which no browser can do (browser spreadsheet libraries neither recalculate formulas nor keep this model's charts and dynamic arrays). A browser could read the five Statistics Canada series directly (their data service allows it, with no key), but FRED does not answer requests from other websites, so FRED data could only be added from files you download yourself. A values-only browser data pack is a possible future addition; it is not offered yet.

Data sources

Monthly rows are keyed to the first day of each month from January 1913. History before a series begins stays blank: nothing is interpolated, forward-filled, or replaced by a proxy series. Daily FRED series (DFF, SP500, T10Y2Y) use the last valid observation of each month; for the current, unfinished month these three columns are left blank until the month ends, so a mid-month value is never written as a month-end value.

“Core” here is Statistics Canada's all-items CPI excluding food and energy (tables 18-10-0004 and 18-10-0006), not the Bank of Canada's preferred core measures (CPI-trim, CPI-median). Statistics Canada revises the previous month's seasonally adjusted values every month and the last three years each January, and FRED series such as PCE are revised too; every download fetches the current published values, so re-running a range picks up revisions.

S&P 500 history

FRED publishes only about ten years of S&P 500 history, and S&P Dow Jones Indices restricts its reproduction. The bundled CPI.xlsx therefore contains no S&P 500 values (and no saved results derived from them): column N is filled only when you download with your own FRED key. Because downloads now merge into the sheet, months you downloaded earlier are kept even after they leave FRED's window. The earlier optional Yahoo Finance backfill is no longer available.

This product uses the FRED® API but is not endorsed or certified by the Federal Reserve Bank of St. Louis. Statistics Canada is the source of the Canadian data; this application does not imply Statistics Canada endorsement. Statistics Canada data is used under the Statistics Canada Open Licence. Confirm your organization's rights to S&P 500 data before professional use or sharing a workbook that contains it.

Workbook safety

  • Writes through a private Excel instance and changes contents only inside the owned A:S area of the target sheet. It never inserts or deletes rows, recreates sheets, or changes formulas, formats, named ranges, charts or tables.
  • Downloads are merged: the months you download replace those months in the sheet, and every other month already there is kept, so a single-month update no longer clears the history. Tick Replace all rows (with a confirmation) to make the sheet hold exactly the downloaded months.
  • Macros, events and external-link updates are disabled during the write. Worksheet calculation is suppressed so dynamic-array spills can't change model cells, and the workbook's own calculation mode is preserved. The model sheets are therefore not recalculated by the tool: after a download, open the workbook in Excel, press Ctrl+Alt+F9 and save. Whether Excel recalculates by itself on opening has not been verified.
  • The month range is limited to January 1913 through the current month. Downloads run in the background with progress and a Cancel button; nothing is written until every source has been fetched and checked.
  • .xlsm workbooks are opened with macros disabled and saved in the same format; workbooks with VBA have not been part of the automated tests.
  • Read-only, locked or protected targets, formulas or merged cells inside the raw area, and a missing sheet all fail with a clear message before any change is made.
  • The optional CSV uses the same columns and data with YYYY-MM-DD dates. A CSV failure is reported separately from an Excel write that already completed.

Credentials & privacy

  • You need your own free FRED API key (request one here). It is saved, as plain text in config.toml inside your copy of the tool, only if you tick Remember on this computer. Never share that file.
  • The download contains no API key or other credential; the bundled template's key field is blank, and the bundled workbook has no author names, local paths or add-in references.
  • During a download only series identifiers, dates and your FRED key (to FRED) are sent, to Statistics Canada and FRED. Setup and repair also contact the Python package index (PyPI) and, if you agree to install Python, winget. Your workbook stays on your PC.

Troubleshooting

“The workbook is open” or the write fails

Close the workbook in Excel, make sure the CPI_Downloader sheet exists and is unprotected, and try again on a copy. Excel must be the desktop Windows version.

A source failed and nothing was written

That's deliberate: data is written only when every source succeeded. Check your internet connection and FRED key, then retry. The error names the failing source.

Setup stops before the program opens

Read the message: it names the failing step (Python, dependencies, or config.toml). An invalid config.toml is kept as-is and blocks downloads until fixed; compare it with scripts/config-default.toml. The guide covers each case.
