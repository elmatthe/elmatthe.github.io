Overview

  • One click, 18 series

    Five Statistics Canada CPI series and thirteen FRED series: US CPI, unemployment, fed funds, Treasury yields, the 10y–2y spread, PCE, and the S&P 500.

  • Straight into Excel

    Writes to the CPI_Downloader sheet of your .xlsx or .xlsm model through desktop Excel, and can also save the same data as CSV.

  • Validated first

    All sources are collected and checked before Excel opens. If any source fails, nothing is written.

Desktop only. The tool needs desktop Microsoft Excel for Windows, so there is no web version. Everything you need is in the download.

Data sources

Monthly rows are keyed to the first day of each month from January 1913. History before a series begins stays blank: nothing is interpolated, forward-filled, or replaced by a proxy series. Daily FRED series (DFF, SP500, T10Y2Y) use the last valid observation of each month.

Optional S&P 500 history

FRED publishes only about ten years of S&P 500 history, and that series carries third-party usage restrictions. Setting add_missing_data = true under [sp500_history] in config.toml fills older months from Yahoo Finance ^GSPC daily closes. FRED always wins any overlap, the two sources must agree within 0.005 index points, and any mismatch stops the download before Excel is touched. The default is false, which makes no Yahoo requests.

This product uses the FRED® API but is not endorsed or certified by the Federal Reserve Bank of St. Louis. Statistics Canada is the source of the Canadian data; this application does not imply Statistics Canada endorsement. Confirm your organization's rights to S&P 500 data before professional use.

Workbook safety

  • Writes through a private Excel instance and clears contents only inside the owned A:S area of the target sheet. It never inserts or deletes rows, recreates sheets, or changes formulas, formats, named ranges, VBA, charts or tables.
  • Macros, events and external-link updates are disabled during the write. Worksheet calculation is suppressed so dynamic-array spills can't change model cells, and the workbook's own calculation mode is preserved.
  • Read-only, locked or protected targets, formulas or merged cells inside the raw area, and a missing sheet all fail with a clear message before any change is made.
  • The optional CSV uses the same columns and data with YYYY-MM-DD dates. A CSV failure is reported separately from an Excel write that already completed.

Credentials & privacy

  • You need your own free FRED API key (request one here). It is saved only in config.toml inside your copy of the tool, which the launcher creates from a blank template. Never share that file.
  • The download contains no API key or other credential; the bundled template's key field is blank.
  • Only series identifiers, dates and your FRED key (to FRED) are sent. Your workbook stays on your PC.

Troubleshooting

“The workbook is open” or the write fails

Close the workbook in Excel, make sure the CPI_Downloader sheet exists and is unprotected, and try again on a copy. Excel must be the desktop Windows version.

A source failed and nothing was written

That's deliberate: data is written only when every source succeeded. Check your internet connection and FRED key, then retry. The error names the failing source.

Setup stops before the program opens

Read the message: it names the failing step (Python, dependencies, or config.toml). An invalid config.toml is kept as-is and blocks downloads until fixed; compare it with scripts/config-default.toml. The guide covers each case.
