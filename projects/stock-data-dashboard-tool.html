Overview

  • Performance & risk

    Total and annualized return, annualized volatility, Sharpe ratio, and maximum drawdown for 2–10 securities over nine horizons (1D to 5Y).

  • Correlation & regression

    A correlation heatmap computed over identical trading intervals, with shared-observation counts, diversification flags, and alpha/beta/R² regression against any benchmark.

  • Currency normalization

    Convert every series to USD, CAD, EUR, or GBP before any metric is calculated, using Yahoo Finance FX pairs such as CADUSD=X.

  • Exports

    A five-sheet XLSX workbook plus CSV and JSON downloads, generated in your browser. The desktop app adds Excel/CSV/JPG exports and rolling charts.

      Appearance

      Live data proxies

      Yahoo Finance does not allow direct browser requests from other websites (CORS), so each request is relayed through a proxy. Proxies only carry Yahoo’s response; every response is checked to be Yahoo Finance data for the requested symbol before it is used. They are tried in order; a proxy that fails is skipped for a cooldown period, and the last one that worked is tried first. Only the ticker and date range are sent. Settings here are shared with the Portfolio Rebalancer on this site.

      Data sources & privacy

      • Yahoo Finance is the only market-data source. The web app reads Yahoo's public daily chart endpoint (prices, and FX pairs like CADUSD=X for normalization). The desktop app uses the yfinance library.
      • Proxies are transport only. Yahoo does not allow direct requests from other websites, so the web app relays each request through a public CORS proxy. Every response is checked to be Yahoo chart data for the requested symbol before it is used. Only the ticker and date range are sent.
      • Nothing is uploaded or stored on a server. Results stay in your browser. A 15-minute response cache lives in this tab's session storage; proxy preferences and the theme are kept in this browser's local storage.
      • The offline demo makes no requests. Its prices are generated from a fixed seed and are clearly labelled synthetic.

      Troubleshooting

      “Live data could not be reached”

      Yahoo Finance blocks direct requests from other websites, so the tool reaches it through several free public relays, and their availability varies. Wait a minute and press Retry; relays that fail are skipped automatically and the last one that worked is tried first. The Offline demo works at any time with no connection. Advanced users can optionally add their own relay in the web app's Settings tab.

      A ticker says “no data”

      Use Yahoo Finance symbols: add an exchange suffix for non-US listings (XIU.TO, ISF.L, 7203.T) and ^ for indexes (^GSPC). The rest of the comparison continues without the failed ticker.

      Charts are missing

      Charts use Chart.js from a CDN. If it is blocked, the tables, heatmap, and exports still work.

      The desktop launcher stops with an error

      The launcher names the component that failed and keeps a log in files/test-logs/setup-and-run-latest.log. See the setup guide's troubleshooting section.
