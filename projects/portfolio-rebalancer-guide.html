Using the rebalancer

  1. Choose a mode. New Money gives buy-only trades that never spend more than your budget. Rebalance adds no cash: sells fund the buys, so the plan never spends more than the sales raise.
  2. Choose the reporting currency and the number of rows (Apply Rows, Add Row, Remove Last).
  3. Fill each row: ticker, shares/units, local price, row currency and target weight %. Weights are relative; they're normalised to 100%. As you type a ticker it's checked against Yahoo Finance. You'll see either Verified: VTI (USD) or a hint such as “found as ISF.L (GBP)”.
  4. Optional run options: Fetch live prices and FX rates (internet required), Show Account Type column (warns when a plan would need money moved between TFSA, RRSP, margin and so on), and Export CSV / Export Excel with a file path.
  5. Click Run Rebalance and review the summary, the per-row plan and any warnings. Load Sample fills a demonstration portfolio.

If a live price or FX lookup fails, that row falls back to the price you typed and the output says so. Nothing is silently guessed. Always confirm prices at your broker before trading.

Outputs

  • On screen: totals, the buy/sell/hold plan per row (shares and amount in both local and reporting currency), and warnings.
  • Excel (optional): RB_Summary and RB_TradePlan sheets, which are replaced on each run; other sheets in the workbook are kept.
  • CSV (optional): the trade plan, one row per position.

Troubleshooting

A ticker isn't found, or is found in another currency

Use Yahoo Finance symbols: Canadian listings end in .TO (TSX) or .V (TSX-V), London listings in .L (priced in pence, which the tool converts to pounds). Set the row currency to the currency the listing trades in.

Live prices didn't load

Yahoo Finance may be rate-limiting or unreachable from your network. The plan still runs using your entered prices and warns you. Try again in a few minutes, or untick live fetch.

The Excel file can't be saved

Close the workbook in Excel and choose a folder you can write to.

For developers

scripts/portfolio_rebalancer/core.py holds the rebalancing maths and its three invariants: buys never exceed the budget in New Money; buys never exceed sale proceeds in Rebalance; and a warning whenever the plan implies moving money between account types. The web version implements the same algorithm and is checked against this file by the website's parity tests. The unit tests live in the source repository (files/tests) and are not included in the ZIP:

.venv/bin/python -m pip install pytest
.venv/bin/python -m pytest files/tests -q

On Windows use .venv\Scripts\python.exe.
