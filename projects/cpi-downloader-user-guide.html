Before you start

Operating system
Windows 10 or 11. The tool doesn't run on macOS.
Excel
Desktop Microsoft Excel for Windows. Excel on the web and Excel for Mac can't be automated this way.
Python
You don't need to install it yourself. The launcher uses an existing stable Python {{ p.python }} or offers to install Python 3.14 for your user account only.
FRED API key
Free. Request one from the St. Louis Fed; it takes a couple of minutes.
Administrator rights
Not needed.
Internet
Needed for setup and for every download (Statistics Canada, FRED, and Yahoo Finance only if you enable the optional S&P 500 history).

Install and first run

  1. Download {{ p.zip_name }} and extract it to a normal folder such as Documents. Keep the CPI-Webscraper folder together.
  2. Double-click {{ p.launcher_windows }}. If SmartScreen warns about a downloaded file, choose More info → Run anyway only if you trust the source; on a work PC, ask IT first.
  3. If asked, allow the Python install (Y/N). It uses winget with user scope and leaves PATH unchanged.
  4. The program opens after setup has proven the environment. The first run also creates config.toml from the blank template.
What the launcher does, step by step
  1. Assess: finds a stable Python 3.11–3.14 with tkinter (never the Microsoft Store placeholder), then checks the private .venv: version, exact package pins and real imports.
  2. Repair / provision: rebuilds a missing or broken .venv (keeping a backup until the rebuild succeeds) and installs only what's missing or drifted.
  3. Prove: re-checks the environment and validates config.toml.
  4. Launch and report: opens the program, or stops with a message naming the failing step. Healthy repeat launches skip pip entirely.

Using the program

  1. Make a working copy of files/CPI.xlsx (or use your own model with a CPI_Downloader sheet) and close it in Excel.
  2. Pick Single month or Date range and enter the year and month. Data starts in January 1913; earlier dates are moved to January 1913. Current months may be incomplete or not yet released.
  3. Choose the target .xlsx / .xlsm and, optionally, tick Also export to CSV and choose a file.
  4. Enter your FRED API key. After a successful download it's saved to config.toml so you don't have to type it again.
  5. Click Download & Write to Excel. Every source is collected and validated first; if any fails, nothing is written.

The columns written, their sources and how the workbook is protected are described on the project page.

Configuration (config.toml)

Created in the tool folder on first run from scripts/config-default.toml. Your existing file always takes precedence, and an invalid file is kept unchanged and blocks downloads until you fix it.

SectionSettingMeaning
[workbook]sheet_nameTarget sheet; it must already exist. Default CPI_Downloader.
[fred]api_keyYour FRED key. Blank in the download. Private: don't share this file.
[output]columnsOrdered { id, header } list. You may rename headers and reorder, but keep each ID exactly once. The supplied model's formulas expect the default A–S order.
[sp500_history]add_missing_datafalse (default): FRED only, about ten years. true: fill older months from Yahoo Finance ^GSPC; FRED wins overlaps and a mismatch stops the download.

If you used an older version, a key in the legacy files/config.json is copied into the new config.toml the first time it's created.

Update, move or remove

  • Update: extract the new ZIP to a new folder and copy your config.toml across to keep your key and column settings.
  • Move or reset: run the launcher after moving the folder; it repairs the .venv. To start fresh, delete .venv and run it again.
  • Remove: delete the folder. A per-user Python you agreed to install can be kept or uninstalled normally.

Troubleshooting

“A stable Python 3.11-3.14 installation is required” and the install fails

winget may be missing or blocked. Install Python 3.14 from python.org (Install for me only, with tcl/tk) and run the launcher again.

Setup failed: config.toml

Compare your config.toml with scripts/config-default.toml: every column ID once, headers not starting with =, +, - or @, and add_missing_data exactly true or false. Or rename the file and let the launcher create a fresh one, then re-enter your key.

FRED rejects the key, or a source fails

Check the key at fred.stlouisfed.org and your connection. The error names the failing source; nothing is written when any source fails.

The workbook can't be written

Close the workbook, confirm the target sheet exists and is unprotected, and that the A:S area has no formulas or merged cells. Files in OneDrive are supported, but a local copy is more reliable.

The S&P 500 history check fails

With add_missing_data = true, Yahoo Finance must return enough overlap months that match FRED within 0.005 points. If Yahoo is unavailable or differs, the download stops. Retry later or set it back to false.

For developers

This download is packaged from the canonical elmatthe/CPI-Webscraper repository (version {{ p.version }}). Its launcher and scripts/bootstrap.py are the project's own and differ slightly from the website's other desktop tools (for example --check-only instead of --venv-check). To check the installation without opening the program, run from the tool folder:

Setup_and_Run-cpi-webscraper.bat --check-only

The offline test suite, release gate (scripts/verify.py) and developer notes are in the source repository, not the ZIP.
