Using the simulator

  1. Enter your assumptions: current portfolio, annual contribution and its growth rate, years to retirement and in retirement, expected return (an arithmetic mean, in percent: 7 means 7%), volatility, inflation, retirement spending, CPP/OAS/pension income, and the number of simulations (1–10,000). Load Sample Scenario fills in a random plausible example.
  2. Choose what your spending is in. Retirement-year dollars (the default, as in earlier versions) means the first year of retirement, in that year's prices. Today's dollars converts the amounts with inflation; the line under the form shows the first-year withdrawal the model will use (for example $42,000 today is $88,098 in 30 years at 2.5% inflation).
  3. Optionally enter a random seed. Leave it blank for a new run; the seed used is shown and written to the report. The same seed and inputs give the same results here and in the web version.
  4. Choose the target .xlsx workbook for the report (a new or existing file), and optionally tick Also export CSV and choose a CSV path.
  5. Click Run Simulation. Invalid inputs are named in the status line with the same messages as the web version. Warnings about the assumptions (for example very high volatility) stay listed under the results.

The model (identical to the web version): returns are drawn from a normal distribution each year; contributions and withdrawals happen at year-end; contributions grow yearly until retirement; withdrawals start at spending minus pension income and rise with inflation; a path fails when it reaches $0 or less in retirement.

Outputs

  • Excel report in the workbook you chose, as three sheets that are replaced on each run: MC_Summary (inputs, spending basis, seed, generator, engine version, model, warnings and headline results), MC_Percentiles (10th/25th/50th/75th/90th percentile for every year in nominal and today's dollars, with the retirement year marked) and MC_Chart (fan-chart image, nominal dollars).
  • Existing workbooks: cell values, formulas and formatting on your other sheets are kept, but the library used to write Excel files cannot keep pictures, shapes, text boxes, charts, pivot tables or form controls. If your workbook has any of these, the program lists them and offers to save the report as a new workbook (name (Monte Carlo report).xlsx) instead, leaving your workbook unchanged.
  • CSV (optional): the same layout as the web version's CSV: summary, inputs, seed, generator, engine version, model and warnings, then one row per year with P10–P90 in nominal and real dollars.

Troubleshooting

“Pension income must be less than annual retirement spending”

If guaranteed income covers all spending, there's nothing for the portfolio to fund, so the simulation isn't needed. Adjust either value.

The Excel report can't be saved

Close the workbook if it's open in Excel, and choose a folder you can write to (not a read-only or synced placeholder folder).

“Save the report as a new workbook instead?”

Your workbook contains content that would be lost if the report were written into it (the message lists it). Choose Yes to save a separate report workbook next to it, or No to cancel and pick another file.

For developers

The folder follows a simple layout: scripts/ holds everything the program needs (main.py, the monte_carlo package, bootstrap.py, pinned requirements.txt), config.toml sets the supported Python range and entry point, and files/ holds tests and generated scratch data. Unit tests are included in the source repository (not the ZIP); run them with the project's Python after installing pytest:

.venv/bin/python -m pip install pytest
.venv/bin/python -m pytest files/tests -q

On Windows use .venv\Scripts\python.exe.
