Overview

  • Book to narrated MP3

    Import PDF or TXT files or whole folders and narrate them with Microsoft Edge TTS, or with optional local Kokoro and Chatterbox voices.

  • Six tools, one window

    Switch between narration, M4B and MP3 utilities, cover-image prep and M4B tag editing from one sidebar. Each tool keeps its inputs and settings while you switch.

  • Originals stay safe

    Outputs go to new numbered folders, and filename collisions get numbered names. Only an optional, off-by-default Cover Image mode can replace originals, and it asks first.

No terminal needed. Extract the ZIP and double-click one launcher. First-run setup opens a window with progress and a log, then later launches open the app directly.

Download for macOS
  1. Extract the whole ZIP and keep its contents together. On macOS, move the extracted AudiobookTool-MacOS-v{{ p.version }} folder from Downloads to Desktop or Applications first.
  2. Double-click the launcher for your system: {{ p.downloads.windows.launcher }} on Windows or {{ p.downloads.macos.launcher }} on macOS. If macOS blocks it, right-click the launcher, choose Open, and confirm.
  3. Let first-run setup finish. It prepares a private Python environment and the required libraries, establishes FFmpeg/ffprobe, and offers the optional Kokoro voice-model download. Follow any guidance it shows.
  4. Start narrating or converting. Later launches skip setup and open the app using the prepared environment.

Setup needs an internet connection and some time. Optional local voice models need additional disk space.

Six tools

  • TTS Audiobook

    Turn PDF or TXT files into MP3 narration using online Edge TTS or optional local Kokoro/Chatterbox voices.

  • M4B Converter

    Convert M4B to one MP3 per book, or split into MP3s by chapter, with metadata options.

  • MP3 Tool

    Write tags to track copies, combine tracks into one MP3 per Book, and add or trim time at track ends.

  • M4B Maker

    Build chaptered M4B audiobooks from MP3s with cover art, metadata and series tags.

  • Cover Image

    Make square covers by padding or cropping JPG, PNG or HEIC images, and correct phone-photo orientation.

  • M4B Metadata Editor

    Edit tags, artwork and chapter titles in existing M4B, M4A or MP4 files without re-encoding the audio.

How it works

  1. Choose a tool and import files or folders. Review the order. Where a tool supports it, each folder becomes a separate Book.
  2. Pick a voice or output mode and set metadata, chapters and artwork. Shared settings apply across Books; individual Book settings fill in the rest.
  3. Start and follow the Activity panel. Switch between Summary and Detailed logs. Use Pause/Resume, Cancel or Retry Failed where available.
  4. Click Open Output Folder to find your finished files.

The global Light/Dark toggle changes all six tools and remembers your choice. Change the output location any time in Preferences & Data.

Output and safety

  • Default location: Downloads/Audiobook-Creation-Tool-Outputs, grouped by tool and numbered run, for example M4B-Maker-Outputs/M4B-Maker-1/.
  • Separate runs: new runs use separate folders, and filename collisions receive numbered names.
  • Originals preserved: the one exception is Cover Image's optional Replace original files mode. It is off by default and asks for confirmation on each run.

TTS input: PDF and TXT only. Save TXT files as UTF-8 (with or without a byte-order mark) and re-save other encodings as UTF-8 before importing. PDFs must contain extractable text.

Requirements

Operating system
Windows 10/11 or macOS 12+
Python and FFmpeg
Setup can acquire both when supported tools are available (winget on Windows, Homebrew on macOS) and shows guidance if automatic setup can't finish. Python 3.11 or 3.12 is recommended; setup targets 3.12 for local voices.
Kokoro
Requires Python below 3.13.
Network
Needed for first-run downloads and for Edge TTS narration. Optional local voice models run offline after download.
Disk space
Room for the Python environment, your outputs and any voice models.
